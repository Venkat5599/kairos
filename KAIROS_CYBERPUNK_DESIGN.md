    # Kairos - Cyberpunk Hacker Aesthetic Design

    ## Inspired by the Image: Dark Cyberpunk with Electric Pink

    ---

    ## Color Palette - Cyberpunk Edition

    ### Primary - Electric Pink/Magenta
    ```
    Neon Pink:       #FF006E (Hot magenta, main brand)
    Deep Magenta:    #D90368 (Darker accent)
    Cyber Pink:      #FF1B8D (Bright highlights)
    Gradient:        linear-gradient(135deg, #FF006E 0%, #D90368 100%)
    ```

    ### Secondary - Dark Cyber
    ```
    Deep Black:      #0A0E27 (Almost black, main background)
    Dark Navy:       #1A1F3A (Elevated surfaces)
    Cyber Blue:      #00D9FF (Accent, data streams)
    Purple Haze:     #8B00FF (Mysterious depth)
    ```

    ### Accent Colors
    ```
    Matrix Green:    #00FF41 (Success, completed)
    Warning Orange:  #FF9E00 (Pending, alerts)
    Error Red:       #FF0040 (Errors, critical)
    Ice Blue:        #00F0FF (Info, links)
    ```

    ### Glitch Effects
    ```
    Glitch Pink:     #FF006E with RGB split
    Glitch Cyan:     #00F0FF with offset
    Glitch Yellow:   #FFFF00 with distortion
    ```

    ## Typography - Cyberpunk Style

    ### Display Font
    ```
    Font: 'Orbitron' or 'Rajdhani' (Futuristic, geometric)
    Weights: 900 (Black), 700 (Bold), 600 (Semibold)
    Letter Spacing: 0.05em (Wider, tech feel)
    Text Transform: Uppercase for headings
    ```

    ### Body Font
    ```
    Font: 'Space Grotesk' or 'Inter'
    Weights: 500 (Medium), 400 (Regular)
    Monospace: 'JetBrains Mono' or 'Fira Code'
    ```

    ### Special Effects
    ```
    Glitch Text: Random character flicker
    Scan Lines: Horizontal lines overlay
    CRT Effect: Slight curve and glow
    ```

    ```css
    background-image:
    ```

    **Glitch Effect**
    ```css
    .glitch {
    position: relative;
    animation: glitch 1s infinite;
    }

    .glitch::before,
    .glitch::after {
    content: attr(data-text);
    position: absolute;
    top: 0;
    left: 0;
    }

    .glitch::before {
    color: #00F0FF;
    animation: glitch-1 0.3s infinite;
    clip-path: polygon(0 0, 100% 0, 100% 45%, 0 45%);
    }

    .glitch::after {
    color: #FF006E;
    animation: glitch-2 0.3s infinite;
    clip-path: polygon(0 55%, 100% 55%, 100% 100%, 0 100%);
    }
    ```
